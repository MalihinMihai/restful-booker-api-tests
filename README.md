# restful-booker-api-tests

## Structure

- `clients/` API client
- `tests/api/` TestCase and fixtures

## Running

- python3 -m venv .venv && source .venv/bin/activate
- pip install -r requirements.txt
- cp .env.example .env 
- pytest -s
